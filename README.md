# Data

## Raw data
`raw/logistics_data.csv` is a simulated educational logistics dataset containing shipment-level records.

### Fields
- `Shipment_ID`: unique shipment identifier
- `Transport_Mode`: Road, Rail, Air, or Sea
- `Destination_Region`: operational destination region
- `Quantity`: shipment quantity
- `Shipping_Cost`: estimated shipping cost
- `Delivery_Time`: delivery duration in days
- `Status`: Delivered, In Transit, or Delayed

## Deliberately simulated quality issues
The raw file includes:
- missing numerical values
- missing categorical values
- one duplicate record
- extreme values for outlier detection

These issues are included to demonstrate the preprocessing pipeline.

## Processed data
`processed/cleaned_logistics_data.csv` is generated by the preprocessing workflow. Numerical columns are median-imputed where needed and Min-Max normalized. Potential outliers are reported for investigation rather than blindly removed.
